# Threat model — draft

Priority threats: spoofed DB identity via untrusted GUC; cross-campus data exposure; unauthorized donor access; self-verified contributions; SMTP duplicate submission; malicious file uploads; unapproved public content; secrets in logs; compromised backups; restore replay of old outbox jobs.

For each threat: document actor, trust boundary, exploit, mitigation, automated negative test, residual risk and reviewer.
