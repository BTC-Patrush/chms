# Project charter — draft

Goal: open-source, self-hosted Church Management System for one church with multiple campuses. Maintain the original MVP scope; no silent scope reduction.

Primary constraints: invitation-only adult login; most people need no account; five protected IAM role templates; MFA for Admin/Finance; separate person and user; modular monolith; audit and backup requirements.

**Status:** This document summarizes previous design discussions and is not a substitute for approved source requirements.
